Задание 1. match + HTML: Цвет статуса заказа

  Напиши функцию getStatusBadge(int $status): string, которая возвращает HTML-бейдж с цветом в зависимости от статуса:

      0 → серый бейдж "Pending"
      1 → синий "Processing"
      2 → зелёный "Shipped"
      3 → тёмно-зелёный "Delivered"
      default → красный "Unknown"

  Выведи результат в HTML. Сделай простой CSS для бейджей (круглые углы, padding, цвет фона).
