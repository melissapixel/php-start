Задание 1.3. Случайная цитата из списка

  Задача: PHP хранит массив из 5–7 цитат (можешь взять любые — про программирование, мотивационные, смешные). 
  При каждом запросе PHP выбирает случайную цитату из массива и отдаёт её. 
  JS показывает цитату в #result.

  Дополнительно: PHP также отдаёт номер цитаты (например, "Цитата 3 из 7"), чтобы пользователь видел, сколько всего цитат и какая выпала.
