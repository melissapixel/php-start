🎯 Задание №3 (сложнее) — «Звёздные преподаватели»

ТЗ: Найди преподавателей, у которых средний балл всех их студентов по всем их курсам строго выше общего среднего балла по школе. Для каждого такого преподавателя выведи:

    имя,
    количество его курсов,
    количество уникальных студентов, которые у него учились,
    его средний балл,
    общий средний балл по школе (одним числом, для сравнения).

Отсортируй по убыванию среднего балла преподавателя.

Что должно получиться: таблица teacher_name | courses_count | students_count | teacher_avg | school_avg.

Подсказка: общий средний балл по школе удобно получить через скалярный подзапрос в SELECT или через CROSS JOIN с однорядным результатом. Фильтрацию «выше среднего» — через HAVING. Уникальных студентов считай через COUNT(DISTINCT student_id).
