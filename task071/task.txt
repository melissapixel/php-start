ЗАДАНИЕ 2: Поиск пользователей с фильтрацией

  Требования:

      Создай таблицу users: id, name, email, age, city.
      Заполни таблицу 10-15 тестовыми записями.

      HTML: Форма поиска с полями:
          Текстовое поле для поиска по имени (частичное совпадение).
          Выпадающий список для выбора города.
          Числовое поле для минимального возраста.

      JS: При отправке формы отправляй GET-запрос на /api/users/search.php с параметрами ?name=...&city=...&min_age=....
      PHP: Обработай запрос, выполни SQL с условиями WHERE (используй LIKE для имени, точное совпадение для города, >= для возраста). Верни JSON с найденными пользователями.
      
      JS: Отобрази результаты в таблице на странице.

  Что проверить:

      Динамическое построение SQL-запроса (если параметр не передан, не добавляй условие в WHERE).
      Защита от SQL-инъекций (prepared statements).
      Обработка пустых результатов.
