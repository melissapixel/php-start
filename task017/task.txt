Задание 2: Захват по значению vs по ссылке
  Создай переменную $counter = 0. Напиши два замыкания:

      incrementByValue — увеличивает $counter на 1, захватывая по значению.
      incrementByReference — увеличивает $counter на 1, захватывая по ссылке.

  Вызови оба замыкания по разу. Выведи значение $counter после каждого вызова. Объясни в комментарии, почему результаты разные.
  Смысл: Увидеть разницу между захватом по значению и по ссылке.
